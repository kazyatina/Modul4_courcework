# Проект программы для поиска вакансий
## Описание
Программа, которая будет получать информацию о вакансиях с платформы hh.ru в России, сохранять ее в файл 
и позволять удобно работать с ней: добавлять, фильтровать, удалять.
___
## Активация пространства
poetry init
poetry add pytest
___
## Модули
- class files - модуль для взаимодействия с файлами
- class Api HH - модуль для взаимодействия с API
- class vacancy - модуль для взаимодействия с вакансиями
- add func - дополнительные возможности
___
## Описание модулей
### class files
В нем реализованы следующие классы и методы:
- class FileHandlerBase(ABC) - Абстрактный класс который перечисляет методы наследуемых классов.
- class FileHandlerJob(FileHandlerBase) - Класс для работы с файлом
- - __init__ - Метод для инициализации экземпляра класса.
- - open_file - Метод открытия файла.
- - write - Метод добавления в файл новых вакансий.
- - delete_vacancy - Метод удаления вакансии.
___
### class Api HH
- class HhBase(ABC) - Абстрактный класс который перечисляет методы наследуемых классов.
- class HH(HhBase) - Класс для работы с API HeadHunter.
- - init - Метод для инициализации экземпляра класса. Задаем значения атрибутам экземпляра.
- - load_vacancies - Метод для получения данных от сервера, подключения к API.
___
### class vacancy
- BaseVacancy(ABC) - Абстрактный класс который перечисляет методы наследуемых классов.
- class Vacancy(BaseVacancy) - Класс для работы с вакансиями на HeadHunter.
- - init - Метод для инициализации экземпляра класса. Задаем значения атрибутам экземпляра.
- - __lt__ - Метод для сравнения по зарплате.
- - __validate_name - магический метод для валидация аттрибута "названия" в вакансии.
- - create_vacancies - класс-метод для получения вакансий в виде списка.
- - to_dict - Метод для изменения формата вывода вакансии в словарь.
___
### add func
- filter_vacancies - Фильтрация данных.
- get_vacancies_by_salary - Получение данных по зарплате.
- sort_vacancies - Сортировка данных.
- get_top_vacancies - Вывод ТОП данных по зарплате.
- print_vacancies - Вывод данных в консоль

## Тесты
Проект включает набор тестов для проверки корректности работы.
### Запуск тестов
Для запуска тестов установите pytest:
```
pip install -U pytest
pip install pytest-cov
```
### Структура тестов
Тесты расположены в директории `tests/` и включают проверки для:
* основных функций
* граничных случаев
* обработки ошибок
### Требования
Для запуска тестов необходимы:
```
pytest
pytest-cov
```
### Покрытие тестами
Для проверки покрытия используйте:
```
pytest --cov
```
Для создания html-отчета используйте:
```
pytest --cov=src --cov-report=html
```
